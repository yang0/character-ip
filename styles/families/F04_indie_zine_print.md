# F04 — Indie / Zine / Print

> **v7 Global Override**
> - Reference clothing is not identity unless the user explicitly asks to preserve it.
> - Reference-photo expression is not frozen identity; each variant receives a personality-driven expression.
> - Background-only differentiation does not count as a distinct style. The style must transform the character itself.
> - Adult age impression must remain stable even when the body is compact/Q-stylized.
> - Standard output proportions: recommended 4.2–5.3 heads; style-specific compact ranges are allowed; absolute max 6.0.


> 风格数量：12。完整 ID 范围：`S040–S051`。

## Family Global Recipe

- **tags**: `zine, print, riso, xerox, punk`
- **default head rendering**: `print-process-translated`
- **default identity fit**: `medium-high`
- **default stylization**: `very-high`
- **default proportion**: `4.0–5.5 heads`
- **texture logic**: physical print artifacts, grain, misregistration, carved/photocopy marks
- **palette logic**: limited ink colors, black/cream plus accents
- **outfit logic**: indie street / casual layering
- **personality affinity**: `rebellious / independent / creative / dry`
- **anti-collapse**: preserve print-process evidence; do not clean into vector art

## Whole-Head Rule

参考角色参考模式下，所有本 Family 风格都必须：
- 保留整颗头的身份感和年龄感；
- 把整个头部重新翻译成本风格的媒介/线条/材质；
- 允许选择性放大辨识度高的头部/五官印象；
- 禁止保留摄影式参考角色皮肤、参考角色脑袋拼贴感。
