# F12 — Experimental / Art Character

> **v7 Global Override**
> - Reference clothing is not identity unless the user explicitly asks to preserve it.
> - Reference-photo expression is not frozen identity; each variant receives a personality-driven expression.
> - Background-only differentiation does not count as a distinct style. The style must transform the character itself.
> - Adult age impression must remain stable even when the body is compact/Q-stylized.
> - Standard output proportions: recommended 4.2–5.3 heads; style-specific compact ranges are allowed; absolute max 6.0.


> 风格数量：10。完整 ID 范围：`S141–S150`。

## Family Global Recipe

- **tags**: `experimental, art, collage, abstract`
- **default head rendering**: `experimental-identity-translated`
- **default identity fit**: `medium`
- **default stylization**: `extreme`
- **default proportion**: `3.5–5.5 heads`
- **texture logic**: high-concept analog/graphic process
- **palette logic**: concept-driven, often limited or bold
- **outfit logic**: integrated into experimental shape language
- **personality affinity**: `unconventional / artistic / strange / self-aware`
- **anti-collapse**: experiment must still read as one coherent personal mascot IP

## Whole-Head Rule

参考角色参考模式下，所有本 Family 风格都必须：
- 保留整颗头的身份感和年龄感；
- 把整个头部重新翻译成本风格的媒介/线条/材质；
- 允许选择性放大辨识度高的头部/五官印象；
- 禁止保留摄影式参考角色皮肤、参考角色脑袋拼贴感。
