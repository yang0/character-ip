# F02 — Meme / Doodle / Ugly-Cute

> **v7 Global Override**
> - Reference clothing is not identity unless the user explicitly asks to preserve it.
> - Reference-photo expression is not frozen identity; each variant receives a personality-driven expression.
> - Background-only differentiation does not count as a distinct style. The style must transform the character itself.
> - Adult age impression must remain stable even when the body is compact/Q-stylized.
> - Standard output proportions: recommended 4.2–5.3 heads; style-specific compact ranges are allowed; absolute max 6.0.


> 风格数量：13。完整 ID 范围：`S014–S026`。

## Family Global Recipe

- **tags**: `meme, doodle, ugly-cute, reaction`
- **default head rendering**: `simplified-meme-translated`
- **default identity fit**: `medium`
- **default stylization**: `very-high`
- **default proportion**: `3.2–4.5 heads`
- **texture logic**: naive/rough simplified line with intentional imperfection
- **palette logic**: limited palette, off-white or flat social colors
- **outfit logic**: simple everyday clothing; silhouette first
- **personality affinity**: `deadpan / witty / awkward / self-aware`
- **anti-collapse**: do not add polish that destroys meme timing; preserve adult age

## Whole-Head Rule

真人参考模式下，所有本 Family 风格都必须：
- 保留整颗头的身份感和年龄感；
- 把整个头部重新翻译成本风格的媒介/线条/材质；
- 允许选择性放大辨识度高的头部/五官印象；
- 禁止保留摄影式真人皮肤、真人脑袋拼贴感。
