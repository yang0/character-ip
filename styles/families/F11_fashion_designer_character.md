# F11 — Fashion / Designer Character

> **v7 Global Override**
> - Reference clothing is not identity unless the user explicitly asks to preserve it.
> - Reference-photo expression is not frozen identity; each variant receives a personality-driven expression.
> - Background-only differentiation does not count as a distinct style. The style must transform the character itself.
> - Adult age impression must remain stable even when the body is compact/Q-stylized.
> - Standard output proportions: recommended 4.2–5.3 heads; style-specific compact ranges are allowed; absolute max 6.0.


> 风格数量：13。完整 ID 范围：`S128–S140`。

## Family Global Recipe

- **tags**: `fashion, designer, lookbook, styling`
- **default head rendering**: `designer-character-translated`
- **default identity fit**: `high`
- **default stylization**: `high`
- **default proportion**: `4.7–5.8 heads`
- **texture logic**: stylized editorial/fashion rendering, not photo-real
- **palette logic**: style-led fashion palette
- **outfit logic**: strong garment language while remaining prop-free
- **personality affinity**: `stylish / confident / composed / independent`
- **anti-collapse**: fashion attitude without realistic model anatomy; max 6 heads

## Whole-Head Rule

参考角色参考模式下，所有本 Family 风格都必须：
- 保留整颗头的身份感和年龄感；
- 把整个头部重新翻译成本风格的媒介/线条/材质；
- 允许选择性放大辨识度高的头部/五官印象；
- 禁止保留摄影式参考角色皮肤、参考角色脑袋拼贴感。
