# F09 — Pixel / Digital Native

> **v7 Global Override**
> - Reference clothing is not identity unless the user explicitly asks to preserve it.
> - Reference-photo expression is not frozen identity; each variant receives a personality-driven expression.
> - Background-only differentiation does not count as a distinct style. The style must transform the character itself.
> - Adult age impression must remain stable even when the body is compact/Q-stylized.
> - Standard output proportions: recommended 4.2–5.3 heads; style-specific compact ranges are allowed; absolute max 6.0.


> 风格数量：12。完整 ID 范围：`S103–S114`。

## Family Global Recipe

- **tags**: `pixel, sprite, bitmap, digital-native`
- **default head rendering**: `pixel-digital-translated`
- **default identity fit**: `low-medium`
- **default stylization**: `extreme`
- **default proportion**: `3.2–4.6 heads`
- **texture logic**: pixel/voxel/low-poly/dither logic
- **palette logic**: limited digital palette
- **outfit logic**: simplified digital clothing blocks
- **personality affinity**: `nerdy / clever / understated / internet-native`
- **anti-collapse**: do not become generic game NPC; keep personal avatar cues

## Whole-Head Rule

真人参考模式下，所有本 Family 风格都必须：
- 保留整颗头的身份感和年龄感；
- 把整个头部重新翻译成本风格的媒介/线条/材质；
- 允许选择性放大辨识度高的头部/五官印象；
- 禁止保留摄影式真人皮肤、真人脑袋拼贴感。
