# Module 03 — Persona-Only Mode

## Trigger
没有清晰参考角色身份图，但存在账号 / 文件 / Bio / 内容信息。

## Goal
生成“像这个账号人格”的 Mascot IP，而不是虚构参考角色相似度。

## Extract
- account role
- content domain
- writing tone
- social temperature
- visual taste
- professional aura
- recurring emotional stance
- meme/reaction potential

## Build
形成：
- Base Persona
- age impression range
- gender expression only when supported or explicitly requested
- hairstyle family
- body proportion
- clothing language
- palette tendency

## Expression Rule
不要默认生成“友好微笑账号角色”。

Base Persona 必须进一步编译为：
- expression families
- gaze variation
- head-pose variation
- pose variation

## Guardrails
- 不因职业自动套制服
- AI ≠ cyberpunk
- finance ≠ suit
- female ≠ pink
- male ≠ black techwear
- 不伪称“像本人”
- 成年 persona 不因 Q 化变儿童

## Output
继续进入 150 Style Dynamic Selector + Expression Engine。
